# 🐢 Python Turtle Shapes Playground

A beginner-friendly Python project to draw different shapes using the Turtle graphics module.  
This project helps you understand basic programming concepts like loops, functions, and graphics.

---

## 📌 Features

- Draw multiple shapes:
  - Line
  - Square
  - Triangle
  - Rectangle
  - Circle
  - Star
  - Hexagon
  - Filled Square
  - Spiral Design
  - Flower Pattern

- Simple menu-based input system
- Beginner-friendly code structure
- Easy to modify and experiment

---

## 🛠 Requirements

- Python 3.x installed
- No external libraries required (Turtle comes built-in)

## ⚠️ Important Notes

- Do NOT name your file `turtle.py`  
(It will cause module conflicts)


👉 Enter a number and press Enter  
👉 The turtle will automatically draw the selected shape

---

## 🧠 How It Works

- `turtle.Turtle()` → creates a drawing pen  
- `forward()` → moves the turtle forward  
- `right()` / `left()` → rotates the turtle  
- Loops (`for`) → used to repeat steps for shapes  
- Functions → separate logic for each shape
